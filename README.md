## ⚡ מה זה CSS Transition?

`transition` ב-CSS מאפשר לשנות ערך של מאפיין עיצובי באופן רציף והדרגתי לאורך זמן נתון, במקום שינוי פתאומי ומיידי.

### תחביר מקוצר (Shorthand):
```css
/* מאפיין | משך זמן | פונקציית תזמון | השהיה */
transition: background-color 0.4s ease 0s;
